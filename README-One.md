# ABAJ Monitor One 0.6.8

[Скачать ABAJ Monitor 0.6.8](./ABAJ-Monitor-One-v0.6.8.apk)

Добавлены выбор аудио- и видеозвонка в карточке контакта, шифрованные приглашения, подтверждение входящих вызовов и отдельный аудиорежим с отключённой камерой.

Интернет-звонки используют внешний сервис Jitsi Meet; приглашения отправляются через ntfy.sh. Собственный сервер и общая Wi-Fi сеть не нужны. Для приёма входящего вызова в этой версии приложение должно быть открыто; для надёжных звонков при закрытом приложении понадобится системная push-доставка.

APK подписан тем же тестовым сертификатом, что и версия 0.6.7, и поддерживает обновление без удаления установленных данных.
