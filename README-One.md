# ABAJ Monitor One v0.6.0 — единый Android APK

[Скачать один APK для всех пользователей](./ABAJ-Monitor-One.apk)

**Прямая ссылка для Android:** https://raw.githubusercontent.com/edgar198282-ux/edgar198282-ux/abaj-monitor-downloads/ABAJ-Monitor-One.apk

- Все телефоны устанавливают один файл ABAJ-Monitor-One.apk, без деления на Admin/Client.
- Общий каталог и заявки на добавление доступны только при добровольно включённой видимости; взаимная привязка требует подтверждения.
- Для GPS пользователь отдельно включает передачу и видит постоянное системное уведомление.
- Светлая и тёмная темы; автоматическая проверка новой версии через peer-updates.json.
- Связь использует внешний HTTPS-сервис, без установки Tailscale и без своего Railway.
- Удалённой передачи камеры или микрофона в этой сборке нет.
- Клиенты 0.5.x могут обновляться поверх старого Client, если подпись совпадает. Старый Admin имеет другой package name и требует отдельной установки One.
