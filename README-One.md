# ABAJ Monitor One v0.7.0

[Скачать ABAJ MONITOR 0.7.0](./ABAJ-Monitor-One-v0.7.0.apk)

Тема и язык — компактные соседние кнопки в разделе «Настройки»: светлая/тёмная, русский/армянский. Выбор сохраняется. Добавлена армянская локализация основных экранов и элементов звонков.

Геолокация запускается вручную после разрешения Android на местоположение «Всегда», затем продолжает работать в видимой foreground-службе до ручного отключения. Согласованная передача восстанавливается после перезапуска приложения; после перезагрузки телефона — если это позволяет Android.

📞 Аудиозвонок и 📹 видеозвонок доступны в карточке добавленных контактов, работают через внешний сервис Jitsi Meet, приглашения передаются через ntfy.sh. Для входящего звонка нужно открытое приложение или касание уведомления. Надёжная доставка звонков при закрытом приложении не гарантируется.

Автообновление подключено. APK 0.7.0 подписан сертификатом версии 0.6.9.
