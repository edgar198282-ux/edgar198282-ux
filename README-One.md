# ABAJ Monitor One 0.6.9

[Скачать ABAJ Monitor One 0.6.9](./ABAJ-Monitor-One-v0.6.9.apk)

Настройки упрощены: кнопки «Источник обновлений», «Тёмная/Светлая тема» и «Проверить на моём телефоне» скрыты с экрана, а тема переключается маленьким значком справа в шапке.

В «Люди» под каждым сохранённым контактом видны отдельные кнопки 📞 Аудио и 📹 Видео. Интернет-звонки используют Jitsi Meet, а приглашения передаются через существующий шифрованный ntfy.sh-канал. Для входящего вызова в текущей реализации нужно открытое приложение.

Обновление APK сохранено и подписано тем же сертификатом, что 0.6.8. Для установки поверх приложения не требуется удалять пользовательские данные.
